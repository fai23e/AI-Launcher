# 🚀 AI Launcher: AIサービスへの超高速アクセス

[![AI Launcher Demo](https://via.placeholder.com/800x400.png?text=AI+Launcher+Demo+GIF)](https://via.placeholder.com/800x400.png?text=AI+Launcher+Demo+GIF)

**AI Launcher**は、よく使うAIサービスにキーボードショートカット一つで瞬時にアクセスできるChrome拡張機能です。
`Ctrl+Shift+Space` でランチャーを開き、割り当てられたキーを押すだけ。思考を中断することなく、必要なAIツールを呼び出せます。

---

## ✨ 主な機能

-   **⚡ 超高速な起動**: `Ctrl+Shift+Space` ですぐにランチャーが起動。マウス操作は不要です。

-   **👆 ワンキーアクセス**: 各AIサービスに割り当てられたショートカットキー（例: `C` でChatGPT）を押すだけで、即座にサービスが開きます。

-   **🔧 柔軟な起動方法のカスタマイズ**:
    -   **ポップアップ or 新規タブ**: 設定画面から、サービスをコンパクトな「ポップアップウィンドウ」で開くか、ブラウザの「新しいタブ」で開くかを選択できます。
    -   **Shiftキーで動作反転**: `Shift` キーを押しながらショートカットを起動すると、設定した方法とは逆の動作で開きます。タブ派もウィンドウ派も、その時の気分で使い分けられます。

-   **🎨 洗練されたUI**:
    -   必要な情報が一目でわかる、クリーンで直感的なデザイン。
    -   ランチャーウィンドウは常に画面中央に表示され、作業の邪魔になりません。

-   **🛠️ 簡単なカスタマイズ**:
    -   ショートカットキー、サイト名、URL、説明を自由に追加・編集・削除できます。
    -   設定のエクスポート・インポート機能で、環境の移行やバックアップも簡単です。

---

## 🚀 使い方

1.  **ランチャーを開く**:
    -   `Ctrl+Shift+Space` を押してランチャーウィンドウを開きます。
    -   もう一度同じショートカットキーを押すか、`Escape` キーで閉じます。

2.  **サービスを起動する**:
    -   ランチャーに表示されているサービスのショートカットキー（例: `C`）を押します。
    -   `Shift` を押しながらキーを押すと、設定とは逆の方法で開きます。

3.  **設定ページを開く**:
    -   ブラウザのツールバーにある **AI Launcher** のアイコンをクリックすると、設定ページが開きます。

---

## 🔧 カスタマイズ

### ショートカットの変更
-   **ランチャー起動**: `chrome://extensions/shortcuts` を開き、AI Launcherのショートカットキーを任意のものに変更できます。
-   **サービスごとのキー**: 設定ページから、各サイトに割り当てるキー（a-z, 0-9など）を自由に変更できます。

### サイトの管理
-   設定ページでは、デフォルトで登録されているAIサービスを編集・削除したり、自分のお気に入りのサイトを自由に追加したりできます。

---

## 🛠️ インストール方法

1.  **リポジトリをダウンロード**:
    -   このページの上部にある `[<> Code]` ボタンをクリックし、`[Download ZIP]` を選択してリポジトリをダウンロードします。
    -   ダウンロードしたZIPファイルを解凍します。

2.  **拡張機能を読み込む**:
    -   Chromeのアドレスバーに `chrome://extensions` と入力し、拡張機能管理ページを開きます。
    -   ページの右上にある **「デベロッパー モード」** のスイッチをオンにします。
    -   **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックし、先ほど解凍したフォルダを選択します。

3.  **完了！**:
    -   ツールバーにAI Launcherのアイコンが表示されたらインストール完了です。`Ctrl+Shift+Space` でランチャーを起動してみましょう！

## 📖 ショートカットキー一覧 (デフォルト)

| キー | サービス名    | 説明                                                                   |
| :--- | :------------ | :--------------------------------------------------------------------- |
| `B`  | Image Creator | アイデアから画像を生成したいときに。                                     |
| `C`  | ChatGPT       | 文章作成、ブレインストーミング、要約など、万能的な対話と思考支援。         |
| `F`  | Felo          | 会議や動画のリアルタイム翻訳・文字起こしに。                             |
| `G`  | Gemini        | マルチモーダル入力で高度な推論をしたいときに。Googleサービスとの連携も。 |
| `J`  | Jules         | ソフトウェア開発のコーディング支援、デバッグ、ドキュメント作成に。       |
| `K`  | Claude        | 長文の読解・要約や、より自然な対話を行いたいときに。                     |
| `M`  | MS Copilot    | Microsoft 365アプリとの連携や、最新情報を元にした回答が必要なときに。    |
| `P`  | Perplexity    | 正確な情報源を伴う回答や、深い調査をしたいときに。                       |
| `S`  | Genspark      | 新しいアイデアの探求や、多様なタスクに対応できるAIを探しているときに。     |
| `X`  | Grok          | X(旧Twitter)の情報を活用した、リアルタイム性の高い回答が欲しいときに。   |
